Who can help with this?

An AI model reads the public profiles and publication abstracts published on this site, then names faculty and papers and cites the record behind each suggestion. It can be wrong, and every citation links to the record so you can check it. Your question is sent to Google Cloud to be answered; if the assistant is unavailable, this view falls back to keyword matches searched in your browser.

How this network is built, and what it leaves out

A link is drawn when the publication pipeline attributes the same work to two faculty members. Those attributions come from each faculty member’s own University-of-Utah-affiliation PubMed query, so the network is a floor, not a census: a missing link does not mean two people have never worked together. Matching the full author lists by name would find roughly twice as many links, but it needs author disambiguation this project does not yet do reliably — only one faculty record carries an ORCID, and the roster already contains a surname-and-initials collision.

Publication collection is also capped per faculty member, so the most prolific people have their number of collaborators biased downward. Only faculty with at least one departmental co-author appear, and only where their connected group holds at least five people — smaller pockets are left out because they crowd the canvas without showing a structure worth reading. External co-authors are not shown, and no link distinguishes a first author from a middle one.
