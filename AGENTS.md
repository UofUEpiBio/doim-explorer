# Contributor protocol

Before starting work, read `docs/doim-migration-plan.md` and inspect its evidence links. Keep a
checklist item unchecked until its stated verification passes; update the checklist and its evidence
in the same commit as the completed work. Do not mark partially implemented work complete.

Any commit created by Codex in this repository must include this Git trailer:

```text
Co-authored-by: OpenAI Codex <noreply@openai.com>
```

This applies to the initial commit and to all later Codex-assisted commits.
